# GymCraft 1.3.1+mc1.21.1

本次补丁版本将 1.3.1 的线程安全修复、性能测评指标和 Python 类型信息同步到 Minecraft 1.21.1。gRPC 协议与 1.3.0 保持一致。

## 修复与改进

- reset、step 的任务评估与响应构造，以及 Connect 的环境元数据和组件空间读取，统一切换到 Minecraft 服务端线程执行，避免 RPC 线程访问实体与世界状态。
- `mining` 环境的里程碑和终止判定只读取当前 step 的观测；物品里程碑以背包观测为准，不再把区域内已放置的工作台或熔炉计为背包里程碑。
- 新增默认关闭的 tick 指标采集，可导出每 tick 耗时、开始及完成的步进数量等 CSV 数据，并补充 reset、step、动作批次和观测组合的 Profiler 分区。
- Python 包新增 `py.typed`，安装后可被 mypy 等类型检查工具识别为带类型信息的包。

## 升级说明

- 模组和 Python 客户端均升级到 **1.3.1**，不要混用旧版模组与新客户端。
- `mining` 判分语义有上述调整；依赖“放置工作台或熔炉即完成里程碑”的 Agent 需要改为将目标物品放入背包。
- 本版本不引入新的 gRPC 协议变更。

## 兼容性

| 组件 | 要求 |
|---|---|
| Minecraft | 1.21.1 |
| NeoForge | 21.1.250 |
| Java | 21 |
| Python | ≥ 3.11 |

## 安装

```powershell
pip install --upgrade "gymcraft==1.3.1"
# 需要 MCP 入口时安装可选依赖。
pip install --upgrade "gymcraft[mcp]==1.3.1"
```

模组附件：`gymcraft-1.3.1+mc1.21.1.jar`。Python 客户端与其他 MC 适配版本共用 `gymcraft==1.3.1`。
