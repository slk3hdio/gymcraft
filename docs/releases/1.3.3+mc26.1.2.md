# GymCraft 1.3.3+mc26.1.2

本次版本新增 `respawn` 复活动作、`wait_player_message` 待机动作与 `general` 通用环境，Python 客户端新增异步 API 与 TOML 配置，并对导航终点修正、破坏动作与附近方块观测做多处改进。gRPC 协议仅做向后兼容的新增，旧 1.3.x 客户端仍可连接新服务端。

## 新增

### 环境与动作

- 新增 `respawn` 复活动作：agent 死亡后重召唤复活（同 UUID 新实例替换），复活不中断批次。复活位置经环境构造期配置（`RespawnTarget` 位置+维度；null = 死亡维度原地），配置目标时跨维度重召唤，`general` 环境固定复活回环境基线出生位置。配合 reset option `keep_inventory`（默认 true）：死亡时整体捕获物品栏快照并取消原版掉落，复活时原样恢复；`keep_inventory=false` 时走原版掉落，物品留在死亡点可捡回、复活空手。
- 新增 `wait_player_message` 待机动作：等待指定玩家发出新的聊天消息后完成，只看动作开始后的新消息，玩家名匹配忽略大小写，超时由 step 共享超时处理。
- 新增 `general` 通用环境类型：无任何自动终止条件，死亡不再终止 episode（由 `respawn` 复活），episode 长度完全由客户端控制。
- `look_at` 新增槽位查询目标：以统一 `slot_id` 只读查询自身物品栏槽位并返回物品描述，不移动视线；实体目标覆盖掉落物；成功 description 携带目标描述。

### Python 客户端

- 新增异步 API（基于 `grpc.aio`）：`AsyncGymCraftEnv`（`await AsyncGymCraftEnv.connect(...)` 建立会话）、`AsyncLLMGymCraftEnv` 与 `async_list_environments`、`async_chat_completion_text`。同步与异步入口并行保留，动作编码、观测解包、DSL 与渲染逻辑共享。
- 新增 TOML 配置：`gymcraft.config` 提供严格 TOML 加载与 `GymCraftConfig`（含 `LLMEnvConfig`/`RenderConfig`/`CompletionsConfig`），可直接注入 `GymCraftEnv`/`LLMGymCraftEnv`；LLM 调用支持传入补全参数（temperature 等）；默认读取 `config.toml`，demos 未指定 `--config` 时自动加载。

## 改进

- `move_to` / `swim_to` 终点修正复刻原版 `findSurfacePosition` 语义：实心方块上移到其上方第一个可站面、空气格吸附到下方支撑面、液体等非固体格保持原格；发生修正时完成 description 携带提示，details 的 `target_correction` 报告修正码、`requested` 报告原始请求坐标。到达判定改为三维欧氏距离。
- `pick_up_item` 支持水域两栖导航，可在水中、水面与陆地之间规划路径。
- `break_block`：拦截纯流体目标不再磨挖水/岩浆；空目标视为完成而非失败；工具不正确不掉落时 description 携带提示。
- `nearby_blocks` 观测记录可穿过的非空气方块（铁轨、蜘蛛网、火把等），同时仍作为扫描节点穿过继续扩展。
- `chat` 观测按 episode 清空历史：reset 后不再回放 reset 之前的消息，共享缓冲与其他环境不受影响。
- 菜单动作反馈改进：reset 丢弃区域外基线实体等场景下的逐项反馈更明确。
- `McEnv` 接口扩展：新增 `findActionComponent`、`getActionComponentSpace` / `getObservationComponentSpace`、`lastResetOptionsView`、`stateRegion`。

## 修复

- 修复 agent 跨维度后环境连接丢失的问题。
- 修复可视化订阅不跟随 agent 的问题，维度变化与重生后不再失效。
- 修复 reset 未丢弃区域外基线实体的问题。
- 修复 `player_sim` 攻击范围与玩家不一致的问题。

## 升级说明

- 模组和 Python 客户端均升级到 **1.3.3**，不要混用旧版模组与新客户端。
- gRPC 协议为向后兼容新增：旧客户端仍可连接新服务端；`respawn`、`wait_player_message` 与 `look_at` 槽位查询为新能力，旧服务端不支持。
- 替换模组 JAR 并重启游戏或服务器即可；世界中的场景残留不受影响。

## 安装

```powershell
pip install --upgrade "gymcraft==1.3.3"
# 需要 MCP 入口时安装可选依赖。
pip install --upgrade "gymcraft[mcp]==1.3.3"
```

模组附件：`gymcraft-1.3.3+mc26.1.2.jar`。
