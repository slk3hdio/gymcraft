# GymCraft 1.3.2+mc1.21.1

本次补丁版本将 `protobuf-java-util` 缺失导致 `Connect` 失败的修复同步到 Minecraft 1.21.1。gRPC 协议与 1.3.1 保持一致。

## 修复

- 将 `protobuf-java-util:4.30.2` 通过 JarJar 内嵌进模组 JAR，确保运行环境包含 `com.google.protobuf.util.JsonFormat`。
- 修复 `Connect` 转换环境 metadata 时抛出 `NoClassDefFoundError`，导致客户端收到 `ALREADY_EXISTS: Failed to read environment on server thread` 的问题。

## 升级说明

- 模组和 Python 客户端均升级到 **1.3.2**，不要混用旧版模组与新客户端。
- 替换模组 JAR 并重启游戏或服务器即可，无需重建已有环境。
- 本版本不引入新的 gRPC 协议变更。

## 兼容性

| 组件 | 要求 |
|---|---|
| Minecraft | 1.21.1 |
| NeoForge | 21.1.250 |
| Java | 21 |
| Python | ≥ 3.11 |

## 安装

```powershell
pip install --upgrade "gymcraft==1.3.2"
# 需要 MCP 入口时安装可选依赖。
pip install --upgrade "gymcraft[mcp]==1.3.2"
```

模组附件：`gymcraft-1.3.2+mc1.21.1.jar`。Python 客户端与其他 MC 适配版本共用 `gymcraft==1.3.2`。
